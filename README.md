## 📌 Project Overview
This repository contains the framework for a **Cloud-Native Geospatial (CNG)** data sharing system. It is designed to handle Big Data analytics using a 100% Free and Open Source Software (FOSS4G) stack. 

The project bridges Asian Big Data initiatives (Japan's Project PLATEAU, JAXA) with East African regional monitoring (Jinka Regional Veterinary Laboratory, Ethiopia).

## 🚀 One-Click Reproducibility
We use Docker to ensure this research can be replicated with a single command.

### Prerequisites
- Docker and Docker-Compose
